# Kano State Out-of-School Children Survey Analysis

Analysis of the 2026 Kano State out-of-school children (OOSC) survey, to show how many children are out of school, where they are, and how the figures differ by gender.

## Objective
Turn raw survey data into clear, decision-ready insights for government and development partners working on out-of-school children in Kano State.

## Data
Survey data collected across 15 local government areas (LGAs) in Kano State. The raw data is not included in this repository, to protect privacy. All results shown here are aggregated.

## Methods
- Data cleaning and processing in Python (pandas)
- Data storage and querying with SQLite and SQL
- Exploratory analysis and visualization
- Interactive dashboard built in Power BI
